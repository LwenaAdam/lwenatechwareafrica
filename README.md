## 🛠️ Installation & Setup

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Quick Start

```bash
# Navigate to the project directory
cd next-app

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000` to see the website.

### Build for Production

```bash
# Create production build
npm run build

# Start production server
npm start
```

## 🎨 Design Guidelines

### DO ✅
- Use primary blue (#232F3E) for headers, footers, main sections
- Use secondary orange (#FF9900) ONLY for CTAs and key highlights
- Keep design clean, minimal, professional
- Follow enterprise-grade aesthetics
- Use consistent spacing
- Maintain clear typography hierarchy

### DON'T ❌
- Don't overuse orange color
- Don't use flashy animations
- Don't clutter the interface
- Don't use too many font styles
- Don't sacrifice readability for style
